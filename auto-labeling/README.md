# Auto-labeling Demo

This folder is the complete submission for the automatic-labeling question:

- `demo_code.py`: runnable local foundation-model labeling pipeline;
- `data/ag_news_sample.csv`: public-task sample and human labels;
- `output/example_predictions.jsonl`: explicitly marked, non-measured output-schema example;
- `REPORT.md`: dataset, method, analysis, human comparison, and improvements;
- `tests/`: deterministic tests for data flow, labeling, and metrics.

See `REPORT.md` for the full discussion, run instructions, and the documented
execution limitation of the included environment.
