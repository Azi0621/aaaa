# 五维数据笔试题

本仓库按题目拆分为独立目录：

- `backend-exam/`：Spring Boot 登录鉴权与受保护的 Hello 接口；
- `python-streaming-api/`：FastAPI + SSE 流式接口演示；
- `mit-blogs-crawler/`：Playwright 与 DrissionPage 两种 MIT Admissions 博客爬虫；
- `auto-labeling/`：基于公开基础模型的 AG News 自动标注方案；
- `agent-data-audit/`：Agent Data 任务包质量审计答卷。

每个目录均包含独立的运行说明。测试与环境限制记录在对应目录的 README 或报告中。
